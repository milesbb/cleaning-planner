# Start or join a home — Claude Context

The screen's notes; the rules for every screen are in `apps/web/CLAUDE.md`.

Start or join a home: start goes to setup (`/setup/rooms`); the invite code field tidies the code with `inviteCodeSchema` and opens `/join?code=`.

Someone who already has a home (from the home switcher or Your account) sees "Add another home" and Back to Today; with no home yet there is no way back. It reads `useHomes`, so the saved list answers at once.
